# F7.1 — Price Lists & Ticket Product Correction

## Price lists

### DNS general price list
- Canonical template: `official_price_list`
- Access: DNS only
- Region scope: `dns_central`
- DNS ticket prices: sourced from DNS Data Entry
- Regional “from” prices: entered manually by DNS

### Regional price list
- Canonical template: `regional_price_list`
- Access: reporting area
- Region scope: resolved from DNS Core access grants
- Price data: sourced from DNS Data Entry for the current reporting area

## Tickets

Tickets are not one combined product.

There are three canonical monolingual ticket products:

1. `ticket_online_weekly_dns` — Dolomiti NordicSki weekly ticket
2. `ticket_online_weekly_area` — reporting-area weekly ticket
3. `ticket_online_daily` — reporting-area daily ticket

All three use the existing formalized presets:
- `DIGITAL_PASS_PRESETS.weekly_dns`
- `DIGITAL_PASS_PRESETS.weekly_area`
- `DIGITAL_PASS_PRESETS.daily_area`

Each ticket is rendered in one document language at a time (DE, IT or EN). The approved translation sets remain attached to the template and are not regenerated when applying it.
